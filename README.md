## ✨ 功能特性

### 核心传输
- 🔄 **协议互通** — 完整兼容 LocalSend v2.2 协议。
- 📱 **极低兼容** — 最低支持 Android 2.3 (API 10)，现代手机也可完美运行。
- ⚡ **原生 HTTP / HTTPS 直连** — 支持无依赖的纯原生 HTTPS 加密传输（基于自签名证书）。同时保留纯 HTTP 模式，以规避旧版安卓没有 TLS 1.2 的兼容性问题。
- 🖥️ **网页端直传 (Web Share)** — 开启服务后，电脑只需打开浏览器输入 `http://手机IP:53317`，即可免安装拖拽传文件。
- 📥 **系统分享直达** — 在相册或文件管理器中选中文件，点击分享到 OldSend，即可快速发送。

### 发送端
- 📁 **多内容发送** — 支持发送 文件、媒体、文件夹、应用(APK)、文本、剪贴板。
- 🎨 **自定义界面** — 完全手写 MD3 (Material Design 3) UI，带丝滑的滑动动画与开关控件。
- 🚀 **设备发现** — 支持局域网组播自动发现与手动添加 IP。

### 接收端
- 🛡️ **前台保活** — 加入前台服务通知，防止在 Android 8.0+ 上被系统杀后台。
- 🔔 **通知栏接收** — 别人发文件时，可以直接在通知栏点击【接收】或【拒绝】。
- 🔒 **PIN 码保护** — 开启后，对方必须输入正确的 4 位 PIN 码才能发文件。
- 📂 **智能分类** — 收到的图片自动进相册，视频进 Movies，其他进 Download。
- 📝 **历史记录** — 自动记录接收的文件，点击即可打开。

### 多语言与设置
- 🌍 **10 种语言区域支持** — 包含简体中文、繁体中文、英语、日语、韩语、德语、法语、西班牙语、俄语、葡萄牙语。支持自动检测系统语言与手动切换。
- ⚙️ **备份与恢复** — 一键将设置导出到剪贴板或从剪贴板导入。
- 🎛️ **自定义设置** — 可修改端口、搜索超时、设备名称、开机自启等。

## 📱 使用说明

### 1. 下载与安装
前往 [Actions](https://github.com/styisme/oldsend/actions) 页面，下载最新的 `oldsend-debug` 压缩包并安装。

### 2. 接收文件
1. 打开 OldSend，点击**启动**（此时通知栏会有一条常驻通知）。
2. 在你的电脑或其他手机上打开 LocalSend。
3. 选择文件发送给你的手机，文件会自动保存在手机存储中。

### 3. 发送文件
1. 点击**扫描**找到目标设备，或点击**加IP**手动输入。
2. 在“选择内容”区域选择你要发送的内容（支持多选）。
3. 点击列表中的目标设备即可发送。

### 4. 网页传文件
1. 确保手机和电脑在同一 Wi-Fi 下。
2. 在电脑浏览器输入 OldSend 界面上显示的 IP 地址（如 `http://192.168.1.100:53317`）。
3. 在网页里直接拖拽文件，就能传到手机上！

### 🔒 关于 HTTPS 加密传输
OldSend 内置了基于 Android 原生 `SSLContext` 的自签名 HTTPS 加密传输，无需第三方依赖。
1. 在 **设置** 页面，打开 **“开启 HTTPS 加密”** 开关。
2. 重启服务（点击主页的停止再启动）。
3. 此时你的设备处于加密传输状态，LocalSend 客户端可以安全地与你握手。
> **注意**：由于使用自签名证书，如果在电脑浏览器直接访问 `https://`，浏览器会提示“连接不安全”。这是正常现象，不影响 LocalSend 客户端之间的加密传输。

## 🚧 架构局限性与风险提示（极度重要）

我们充分意识到 OldSend 作为一个“极限兼容”项目的固有缺陷，请在使用前知悉：

1. **伪安全与 TLS 代沟**：Android 2.3 原生只支持 TLS 1.0，现代设备要求 TLS 1.2+。开启 HTTPS 会导致旧设备与现代设备**握手失败**。即便在现代设备间成功，自签名证书也会在浏览器中触发“不安全”警告。
2. **老旧设备的算力灾难**：在极低配置的安卓设备上开启 HTTPS 加密传输，会导致 CPU 满载、严重发热及传输速度断崖式下跌。
3. **手搓网络底层的脆弱性**：底层 HTTP 服务端/客户端由 AI 辅助生成，未使用成熟的工业级网络库。在弱网、并发异常或 SSL 握手超时时，可能发生卡死或崩溃。
4. **古早工具链的技术债**：为强制支持 API 10，项目锁死了旧版构建环境，失去了引入现代安全库的能力。

**总结**：OldSend 是一个极其疯狂的技术实验。如果你需要日常稳定、快速、安全的文件传输，**请在现代设备上使用官方原版 LocalSend**。OldSend 只建议在极客折腾或特定怀旧场景下使用。

## ⚠️ 已知限制

### 已知未修复的问题（Known Issues）
- **PIN 码输入框玄学失效**：由于纯代码绘制弹窗在部分极低分辨率或特殊 ROM 的设备上，Input 输入框可能会被压缩为高度 0，导致点击修改 PIN 或发送时无法弹出键盘。
- **深色模式“反色”不彻底**：部分第三方系统组件（如某些输入法、系统文件选择器）可能不会跟随 App 强制变暗。
- **长按剪贴板/分享**：部分老旧安卓设备在通过系统分享面板拉起 App 时，会因内存不足导致界面闪退。


- **极老设备的 TLS 限制**：Android 2.3 等极老系统作为发送方时，可能无法与强制开启现代 TLS 1.2/1.3 加密的设备握手，建议在此类设备上使用纯 HTTP 模式。
- **组播限制**：部分公共 Wi-Fi 或路由器开启了 AP 隔离，会导致无法搜索到对方，请改用“添加 IP”或网页传输。
