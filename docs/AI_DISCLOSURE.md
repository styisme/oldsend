# AI 生成说明

本项目（OldSend）在开发过程中大量使用了大型语言模型（LLM）辅助生成代码与文档。

## AI 参与的部分
- 架构设计：分层结构、跨网穿透逻辑、STUN/UPnP 协议手写。
- 业务逻辑：文件并发、断点续传、黑白名单路由分发、剪贴板同步。
- UI 代码：Web SPA 网页开发、自定义 MD3 Switch、深色模式递归遍历。
- 文档与脚本：README、CI 构建脚本、以及用于修复项目的一键 Python 补丁。

## 人类参与的部分
- 需求定义：提出“既要局域网，又要跨网穿透”、“单文件变多选”等极端需求。
- 功能验收：在手表等古早设备上真机测试，把报错日志砸给 AI 修复。
- Bug 定位：解决诸如 `git push -f` 导致代码丢失、变量未加 final 等物理/语法事故。

## 风险提示
由于大量代码为 AI 生成：
- 边缘情况处理可能不完整（如特殊路由器下的 UPnP 失败）。
- 在某些极度特殊的 ROM 上，UI 布局可能依然存在溢出。
