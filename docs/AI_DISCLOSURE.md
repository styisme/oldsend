# AI 生成说明

本项目（OldSend）在开发过程中大量使用了大型语言模型（LLM）辅助生成代码与文档。本文档详细说明 AI 参与的范围与边界。

## AI 参与的部分
以下内容主要由 AI 生成，经开发者审阅后纳入项目：
- 架构设计：分层结构、HTTP 协议交互逻辑。
- 业务逻辑：文件流式传输、组播发现、多语言字典。
- UI 代码：自定义 MD3 Switch 绘制、布局排版、动画效果。
- 文档：README、CHANGELOG、CONTRIBUTING。
- 构建脚本：GitHub Actions workflow（JDK 8 与 SDK 28 的兼容配置）。

## 人类参与的部分
以下决策由开发者负责：
- 需求定义：确定极低版本兼容（Android 2.3）的核心目标。
- 功能验收：实际测试并反馈编译报错、界面遮挡等问题。
- Bug 定位：提供报错日志，调整依赖库选择。

## 风险提示
由于大量代码为 AI 生成，可能存在的问题：
- 边缘情况处理不完整：某些极度特殊的 ROM 可能无法正常运行。
- 兼容性：理论上支持 Android 2.3，但未在极其广泛的旧设备群中验证。
- 安全性：为了兼容性剥离了复杂的 HTTPS 库，仅建议在可信局域网使用。

项目代码使用 MIT 协议，不因 AI 生成而改变许可条款。使用者需自行承担风险。
